# Stories: operating

Roles: **operator** (runs Nightwatch), **org owner**, **team member**, **CI**.

- As an operator, I can run all of Nightwatch on one Cloudflare account,
  with nothing hosted anywhere else.
- As an operator, I can host several products, each with its own projects
  and people, and none can see another.
- As an org owner, I can invite people, put them on teams, and give each
  a role.
- As a team member, I sign in the way I already sign in to our tools.
- As CI, I can upload release artifacts with a token that can do nothing
  else.
- As an operator, I can set how long events, attachments and reports are
  kept, and they are gone after that.
- As an operator, I can see what was accepted, dropped, filtered or
  rate-limited, and why.
- As an operator, I can replay the raw stream of what arrived, to rebuild
  after a bug in processing.
- As an operator, I can see what Nightwatch costs, per product.
- As an operator, I can keep personal data out by rule, and prove what was
  removed.
- As an operator, I can export a project's data and delete it.
- As an operator, I can upgrade Nightwatch without losing an event in
  flight.
