# Stories: triage

Roles: **team member**, **team lead**.

- As a team member, I see one issue for a crash that happened a thousand
  times, with how often, to how many people, since when, and in which
  releases.
- As a team member, I see new issues separately from ones I have already
  looked at.
- As a team member, I can resolve an issue, and it comes back by itself if
  the crash returns in a newer release.
- As a team member, I can resolve an issue "in the next release", and
  events from older releases do not reopen it.
- As a team member, I can archive an issue until it gets worse, until a
  date, or until it happens some number more times.
- As a team member, I see an archived issue return when it starts
  happening much more than usual.
- As a team member, I can assign an issue to a person or a team, and
  Nightwatch suggests who owns it from rules and from the code.
- As a team member, I can merge two issues that are the same crash, and
  split one that is really two.
- As a team member, I can delete an issue and stop future events of it
  from being stored at all.
- As a team member, I can search issues with a query language: status,
  assignee, release, tags, age, counts and free text.
- As a team member, I can save a search I use every day.
- As a team member, I can comment on an issue, and see its history.
- As a team member, I can see bug reports in their own inbox, apart from
  crashes, and triage them the same way.
- As a team lead, I can see the trend of errors per release and per
  project.
- As a team member, I see similar issues suggested when I look at one.
  (Aspiration.)
