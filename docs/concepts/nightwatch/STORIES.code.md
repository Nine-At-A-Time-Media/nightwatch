# Stories: code

Roles: **team member**, **developer**, **reporter**.

- As a team member, I can cut a GitHub issue from a Nightwatch issue or a
  bug report, with the evidence filled in.
- As a team member, I can have a GitHub issue cut for me when a rule says
  so.
- As a team member, I see the GitHub issue's state in Nightwatch, and it
  stays current when someone closes or reopens it on GitHub.
- As a reporter, I learn that my bug was fixed when the GitHub issue it
  became is closed, though I never see GitHub.
- As a team member, I can write a comment on GitHub and choose to have it
  reach the reporter.
- As a developer, I can resolve an issue by naming it in a commit or pull
  request, and it is resolved when that commit ships.
- As a team member, I see the commit that most likely caused an issue,
  and its author.
- As a developer, I can jump from a stack frame to the line in the
  repository.
- As a team member, I can have issues assigned from CODEOWNERS.
- As a developer, I see on my pull request which open issues its code
  touches. (Aspiration.)
- As a developer, I can upload source maps from CI and tie them to a
  release.
- As a developer, I can tell Nightwatch which commits are in a release and
  when it was deployed.
